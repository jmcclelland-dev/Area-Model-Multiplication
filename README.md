# Area Model Multiplication

An interactive practice page for multiplying with the area model.

Students break each factor into place-value parts, multiply the outside numbers to fill each box, then add the partial products (with carry boxes) to find the final answer.

## Options

- **Problem size:** 1-digit × 2-digit, 1-digit × 3-digit, or 2-digit × 2-digit
- **Practice type:**
  - *Fill the boxes*: multiply the outside numbers to fill in each partial product.
  - *Challenge: find the outside*: one or more outside numbers are hidden, and students work backward from the boxes.

Answers are checked as students type, and the page counts how many problems they finish.

## Using it

Open `index.html` in any web browser. You don't need to install anything.

To share it as a website, turn on GitHub Pages for this repository (Settings → Pages → Deploy from branch `main`, folder `/ (root)`).
